# LAB 01 – SOFTWARE REQUIREMENTS SPECIFICATION

## Project Title
**Digital Document Verification System (DDVS)**

## Objective
To prepare a Software Requirements Specification (SRS) document for the Digital Document Verification System in accordance with the IEEE recommended standards.

## Project Description
The Digital Document Verification System is a web-based application that allows authorized organizations to register and issue digital documents. Users can verify document authenticity using a unique Verification ID, QR code, or document upload.

The system checks registered records and document integrity to identify whether a document is Verified, Invalid, Not Found, or Tampered.

## Main Actors
1. General User / Verifier
2. Issuing Organization
3. System Administrator

## Deliverable
The SRS document describes:
- Introduction and project scope
- Overall system description
- External interface requirements
- Functional requirements
- Non-functional requirements
- Database and other requirements
