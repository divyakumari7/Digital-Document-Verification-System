# LAB 02 – USE CASE DIAGRAM

## Project Title
Digital Document Verification System (DDVS)

## Objective
To identify the actors and use cases of the Digital Document Verification System, draw a Use Case Diagram, and specify the role of each actor along with the preconditions, postconditions and functions of each use case.

## Introduction
A Use Case Diagram is a UML behavioural diagram that represents the interactions between external actors and the functionalities provided by a software system.

It helps identify the system's functional requirements from the perspective of its users.

## Actors Identified
1. General User / Verifier
2. Issuing Organization
3. Administrator

## Use Cases Identified
1. Register Account
2. Log In
3. Register Document
4. Verify Document
5. Check Integrity Hash
6. View Verification History
7. Approve Issuing Organization
8. Manage Users
9. Manage Documents

## UML Relationship
The use case Verify Document includes Check Integrity Hash using the `<<include>>` relationship.

## Tools Used
- GitHub – Project documentation and submission.
- diagrams.net (draw.io) – UML diagram creation.

## Deliverables
- Use Case Diagram
- Actor descriptions
- Use Case Descriptions containing preconditions, postconditions and functions
